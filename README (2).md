# Simple To-Do List

A small HTML, CSS and JavaScript learning project. You can add tasks,
click a task to mark it done, and delete tasks.

**Note:** This starter was created with AI assistance as a learning exercise.
I am studying the code and extending it myself.

## How to run
Download `index.html` and open it in any web browser. No installation needed.

## What I am learning
- Basic HTML structure and CSS styling
- JavaScript functions, arrays and objects
- Updating a web page with the DOM
